LT-ViT: A Vision Transformer for Multi-Label Chest X-Ray Classification

Chest X-ray classification can require attention to several possible conditions at once. LT-ViT extends a vision transformer with label tokens that interact with image tokens within the visual backbone. This allows label information and image features at different scales to be learned together without a separate text input. On two public chest X-ray datasets, it outperformed the pure vision transformer systems used as comparators. Its attention pattern also provides a way to inspect predictions without relying on Grad-CAM.

Key result

LT-ViT outperformed the tested pure vision transformers on two public chest X-ray datasets and offered label-based interpretation.
